Custom Agents

Specialized personas that activate automatically or on demand. Save to ~/.claude/agents/
✍️
Copy Critic
@"copy-critic (agent)" — or auto-activates on persuasive text
A direct-response copywriter that reviews any marketing text with brutal honesty. Scores each section, rewrites the 3 worst lines, and gives one overall recommendation.
  • Is the headline specific and benefit-driven (not clever)?
  • Does the opening hook address a pain or desire immediately?
  • Is there a clear, single CTA?
  • Are claims unsupported ("best", "amazing", "revolutionary")?
  • Reading level appropriate? (target: grade 7–8)
File path
~/.claude/agents/copy-critic.md
🔍
SEO Optimizer
@"seo-optimizer (agent)" — auto-activates on HTML/article files
Reviews landing pages and blog content for on-page SEO. Outputs a prioritized fix list (critical / important / nice-to-have) tailored for edtech and info-product niches.
  • Title tag (50–60 chars, keyword-first)
  • H1 presence and search intent match
  • Image alt tags and schema markup (Course, FAQ, Product)
  • Internal linking opportunities
  • Page load factors (large images, render-blocking scripts)
File path
~/.claude/agents/seo-optimizer.md
🚀
Launch Planner
@"launch-planner (agent)"
Full digital product launch strategist. Plans 14-day pre-launch + 7-day open-cart timelines with complete asset checklists, dependencies, and Day 0 go-live checklist.
  • Complete 21-day launch timeline with named milestones
  • All assets listed: pages, emails, posts, ads, tech
  • Dependency map (what must be done before what)
  • High-risk failure points flagged in advance
  • Day 0 checklist — everything that must be live before cart opens
File path
~/.claude/agents/launch-planner.md

Hooks

Automatic behaviors that trigger on Claude's actions. Configure in ~/.claude/settings.json
Auto-Commit on File Write
PostToolUse → Write|Edit
Every time Claude writes or edits a file, it's automatically staged and committed to Git. You never lose a draft — even mid-task.
Add to ~/.claude/settings.json
{ "hooks": { "PostToolUse": [ { "matcher": "Write|Edit", "hooks": [ { "type": "command", "command": "cd \"$CLAUDE_PROJECT_DIR\" && git add -A && git commit -m \"Auto-save: $(date '+%H:%M')\" 2>/dev/null || true" } ] } ] } }
Slack Notification on Task Finish
Stop
When Claude finishes responding to a task, a ping is sent to your Slack channel. Know when a long-running job is done without watching the screen.
Add to ~/.claude/settings.json (replace WEBHOOK_URL)
{ "hooks": { "Stop": [ { "hooks": [ { "type": "command", "command": "curl -s -X POST YOUR_SLACK_WEBHOOK_URL -H 'Content-type: application/json' -d '{\"text\":\"✅ Claude finished a task\"}' > /dev/null" } ] } ] } }

Routines

Scheduled agents that run automatically — even when you're offline. Set up at claude.ai/code/routines
🕵️
Competitor Monitor
Weekdays 8:00 AM
Fetches your top 3 competitor pages every morning and checks if anything changed — headlines, pricing, offers, social proof. Posts a summary to Slack.

Checks: headline changes · new pricing · new testimonials · urgency tactics

Output: Slack message → #marketing · "No changes" if nothing found

💡
Weekly Content Ideas
Sundays 7:00 PM
Every Sunday evening, searches for trending topics in your niche and generates a full 7-day content plan. Saves directly to your Notion content calendar database.

Uses: /content-plan skill + web search for trending topics

Output: New page in Notion "Content Calendar" database

🔎
Landing Page Audit
Fridays 3:00 PM
Audits all your live landing pages — broken links, broken forms, missing alt tags, placeholder text left in, mobile viewport. Saves a pass/fail report.

Checks: 404 links · form actions · image alt tags · placeholder text · viewport meta

Output: audit-YYYY-MM-DD.md saved to project

📈
Monday Performance Digest
Mondays 9:00 AM · API trigger
Feed it last week's metrics via API on Monday morning. Get back a funnel diagnosis, biggest bottleneck, 3 priority actions, and one test to run this week.

Trigger: POST your metrics as text via API each Monday

Output: Slack #growth → diagnosis + 3 actions + 1 test hypothesis

API trigger (send your metrics)
curl -X POST https://api.anthropic.com/v1/claude_code/routines/{ID}/fire \ -H "Authorization: Bearer {TOKEN}" \ -d '{"text": "Last week: 1200 visitors, 3.2% CVR, $4,800 revenue..."}'

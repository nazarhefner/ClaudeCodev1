# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Git & GitHub Workflow

This project uses Git with a remote on GitHub at `https://github.com/nazarhefner/ClaudeCodev1`.

- After every meaningful change, create a commit with a clean, descriptive message and push to `origin main`.
- Commit messages should use imperative mood and explain *what* and *why* (e.g. `Add user auth endpoint` not `added stuff`).
- Never leave uncommitted changes at the end of a task.

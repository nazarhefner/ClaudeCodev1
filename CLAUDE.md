# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Git & GitHub Workflow

This project uses Git with a remote on GitHub at `https://github.com/nazarhefner/ClaudeCodev1`.

Commit and push **during** work, not just at the end. Each logical unit of progress (a new file, a working feature, a bug fix, a refactor) should be its own commit pushed immediately. This ensures no work is ever lost and the GitHub history always reflects the current state.

- Commit after every logical unit of progress and push to `origin main` right away — do not batch up work into one large commit at the end.
- Commit messages must use imperative mood and explain *what* and *why* (e.g. `Add login form validation` not `changes`).
- Never leave uncommitted changes at the end of a task.
- If a task spans multiple steps, commit after each step so progress is continuously saved to GitHub.
